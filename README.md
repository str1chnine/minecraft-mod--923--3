# minecraft-mod--923--3
Палунина и Столба. 
Блок Сухарь. 
ИСРПО
Создается блок в Майнкрафте в виде сухаря. 
Является предметом питания, техника использования похожа на Торт, но немного с дополнительными функциями, в виде плесневения.

Структура проекта
- `src/main/java` — исходный код (Java-классы).
- `src/main/resources` — ресурсы (конфигурации, картинки).

## Игровой объект
- **Имя:** bread_block
- **Назначение:** Восполняет голод.
