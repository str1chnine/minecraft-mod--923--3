# minecraft-mod--923--3
Палунина и Столба. 
Блок Сухарь. 
ИСРПО
Создается блок в Майнкрафте в виде сухаря. 
Является предметом питания, техника использования похожа на Торт, но немного с дополнительными функциями, в виде плесневения.

Структура проекта
- `src/main/java` — исходный код (Java-классы).
- `src/main/resources` — ресурсы (конфигурации, картинки).

## Игровой объект
- **Имя:** bread_block
- **Назначение:** Восполняет голод.

## Свойства объекта
- **Прочность:** 2.0 — блок ломается рукой, как дерево.
- **Сопротивление взрыву:** 6.0 — устойчив к взрывам.
- **Свечение:** 3 — блок слегка светится в темноте (как сухарь, прожаренный на солнце).

## Дополнительное поведение объекта (ЛБ-10)

**Сценарий использования:**
1. **Исходное состояние:** Игрок находится в мире, блок «Сухарь» установлен на землю.
2. **Действие игрока:** Игрок нажимает правую кнопку мыши (ПКМ) по блоку «Сухарь».
3. **Ожидаемый результат:** В чате появляется сообщение «Хруст! Сухарь очень вкусный!», шкала голода игрока восполняется, а блок визуально уменьшается (меняется его стадия).

*Условие отличия:* Поведение срабатывает только для блока `minecraft-mod:bread_block`. При клике по обычным блокам (камень, земля) сообщение не появляется.
