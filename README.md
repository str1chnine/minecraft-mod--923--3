# BlockBread (Мод "Сухарь")

## Назначение
Мод добавляет в игру блок «Сухарь», который восполняет голод игроку. Игрок может создать его из хлеба, разместить в мире и постепенно откусывать, как торт.

## Требования совместимости
*   **Minecraft:** 1.21.1
*   **Fabric Loader:** >= 0.16.7
*   **Fabric API:** 0.106.0+1.21.1
*   **Java:** JDK 21

## Установка
1. Установите Minecraft 1.21.1 и Fabric Loader (версия 0.16.7 или новее).
2. Скачайте и поместите `fabric-api` в папку `mods`.
3. Поместите итоговый JAR файл `minecraft-mod-1.0.0.jar` в папку `mods`.
4. Запустите игру.

## Как получить и использовать объект
*   **Получение в креативе:** Блок находится во вкладке «Строительные блоки» (Building Blocks).
*   **Крафт:** Положите 9 батонов хлеба сеткой 3х3 в верстак.
*   **Поедание:** Нажмите ПКМ (правую кнопку мыши) по установленному блоку. Блок уменьшится, а вы восстановите голод.
*   **Гниение:** Если оставить блок в мире надолго, он начнет портиться и покроется плесенью. Испорченный блок есть нельзя.

## Известные ограничения
*   Блок не может быть съеден, если шкала голода игрока полностью заполнена.
*   Модель откусанного блока выглядит ниже стандартного куба (используются модели торта).
