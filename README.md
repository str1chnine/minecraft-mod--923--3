# BlockBread (Мод "Сухарь")

## Назначение
Мод добавляет в игру блок «Сухарь», который восполняет голод игроку. Игрок может создать его из хлеба, разместить в мире и постепенно откусывать, как торт.

## Совместимость
*   **Minecraft:** 1.21.1
*   **Fabric Loader:** 0.16.7 или новее
*   **Fabric API:** 0.106.0+1.21.1
*   **Java:** JDK 21

## Установка
1. Установите Minecraft 1.21.1 и Fabric Loader.
2. Скачайте мод **Fabric API** и поместите его в папку `mods`.
3. Соберите проект или скачайте готовый файл `minecraft-mod-1.0.0.jar`.
4. Поместите JAR-файл мода в папку `mods`.
5. Запустите игру (профиль Fabric).

## Использование
*   **Крафт:** Положите 9 батонов хлеба сеткой 3х3 в верстак.
*   **Поедание:** Нажмите ПКМ по установленному блоку, чтобы утолить голод (блок уменьшится).
*   **Гниение:** Со временем блок портится и покрывается плесенью. Испорченный блок есть нельзя.

## Известные ограничения
*   Блок нельзя съесть, если шкала голода заполнена.
*   Модель откусанного блока использует стандартную модель торта (он ниже куба).
